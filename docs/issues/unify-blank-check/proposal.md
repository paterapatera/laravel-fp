# お知らせの空白判定を一つにする

## Why

お知らせの登録と公開判定が、同じ空白判定を別々の関数で持っている。判定が二つあると、片方だけ変わったときに登録の拒否と公開対象が食い違う。

## What Changes

- 題名、要約、本文が空白だけかを一つの関数で判定する。
- 登録と公開判定の両方がその関数を使う。

## Impact

- Type: refactor
- Capabilities: none
- Steering: none
- Decisions: none
- Code: お知らせの登録と公開判定

## Out of Scope

- 画面の表示、文言、遷移
- 保存される文字と、保存の有無
- 空白だけの定義
- 状態と公開期間による公開判定
