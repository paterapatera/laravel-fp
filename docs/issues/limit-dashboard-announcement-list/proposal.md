# ダッシュボードのお知らせ一覧を10件に限る

## Why

ダッシュボードは公開対象のお知らせを、今の並びのまますべて出す。件数が増えると一覧が長くなる。

## What Changes

- ログイン済みの利用者がダッシュボードを開いたとき、公開対象の一覧は今の並び順のまま先頭10件までになる。
- 11件目以降は一覧に出ない。
- 公開対象が0件のときは、今の空の一覧のままである。
- 上限は10件である。

## Impact

- Type: feat
- Capabilities: Modified /specs/announcements/read
- Steering: none
- Decisions: none
- Code: ダッシュボードのお知らせ一覧

## Out of Scope

- 詳細を直接開く挙動
- 並び順
- 空の一覧の見せ方
- 11件目以降を一覧に戻すページングや追加表示
- 件数以外の単位で上限を決めること
- お知らせの登録と公開判定
