# 登録した下書きに公開期間を残す

## Why

管理者は後で公開するときの開始と終了を、登録の時点で下書きに残したい。今の登録は送られた期間を捨て、開始と終了を空のままにする。

## What Changes

- 登録画面で開始と終了を入力できる。
- 開始と終了が両方空なら、下書きの開始と終了は空のまま保存する。
- 開始と終了が揃い、終了が開始以降なら、その期間を状態が draft の下書きに保存する。
- 終了が開始より前のとき、または片方だけのときは、お知らせを追加せず、その不正を示す。

## Impact

- Type: feat
- Capabilities: Modified /specs/announcements/register
- Steering: none
- Decisions: none
- Code: 登録画面、下書きの保存、期間の検証

## Out of Scope

- 状態を published にすること
- 期間による一覧や詳細への表示
- 保存済みのお知らせの期間の修正
- 登録の成功画面に期間を出すこと
