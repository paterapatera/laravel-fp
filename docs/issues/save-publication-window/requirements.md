# Context

## Actors

- 管理者は、登録画面で下書きの開始と終了を残す。
- 管理者でないログイン済みの利用者と、未ログインの訪問者は、登録できない。

## Current behavior

- REQ-ANR-4 は、登録画面を開くと題名、要約、本文の入力が空であることを求める。
- REQ-ANR-11 と REQ-ANR-12 は、空白だけの題名、要約、本文を追加せず、その不足を示す。
- REQ-ANR-13 は、不足を示している間、入力済みの文字を残す。
- REQ-ANR-14 は、空白以外の題名、要約、本文で状態が draft のお知らせを一件追加する。
- REQ-ANR-15 は、登録の成功で開始と終了を空にし、送られた期間も捨てる。
- REQ-ANR-9 と REQ-ANR-10 は、管理者以外の登録ではお知らせを追加しない。
- DATA-ANN-1 の startsAt と endsAt は、任意の日時である。
- 登録の Scope は、公開期間の保存を範囲外にしている。

## Proposal Coverage

- 登録画面で開始と終了を入力できる。: REQ-ANR-4
- 開始と終了が両方空なら、下書きの開始と終了は空のまま保存する。: REQ-ANR-14, REQ-ANR-15
- 開始と終了が揃い、終了が開始以降なら、その期間を状態が draft の下書きに保存する。: REQ-ANR-14, REQ-ANR-NEW-1
- 終了が開始より前のとき、または片方だけのときは、お知らせを追加せず、その不正を示す。: REQ-ANR-NEW-2, REQ-ANR-NEW-3, REQ-ANR-NEW-4, REQ-ANR-NEW-5

### SECTIONS

#### Scope
- base: 1a6db9a0f67b

登録の入口、下書きの追加、空白だけの入力の拒否、空または時までの公開期間の保存、片方だけ・逆転・時までの日時でない期間の拒否、成功した結果の再送。保存済みのお知らせの編集と削除、管理者権限の付与、管理者フラグの表示、状態を published にすること、期間による一覧と詳細への表示、登録の成功画面に期間を出すことは範囲外である。一覧と詳細は [お知らせの閲覧](/specs/announcements/read/) に属する。お知らせの保存項目は [お知らせの記録](/specs/announcements/read/data.md) に属する。

#### Definitions
- base: 2e6996b0e2eb

登録画面は、新しいお知らせの題名、要約、本文、開始、終了を入力する画面である。空白だけとは、文字が無いか、空白文字だけであることをいう。題名、要約、本文、開始、終了の空白だけは空と同じである。時までの日時とは、年月日と、0 以上 23 以下の整数の時だけからなり、分、秒、タイムゾーンの指定が無い日時をいう。その時は UTC のその時である。
